# Code Availability

All analysis code used in this study is available at https://github.com/ZhijunGuo129/nsclc-radiosensitivity-radiogenomics-analysis. The code version corresponding to the submitted manuscript is archived in Zenodo at https://doi.org/10.5281/zenodo.21809509.

Raw imaging and transcriptomic data are not redistributed with the code. They must be obtained from the source repositories listed in the manuscript Data Availability statement and in `data/README.md`.
