# Data access

Raw and participant-level derived data are not redistributed in this repository.

The analysis uses public resources that must be obtained from their original repositories:

- the Cleveland RadioSet distributed through RadioGx;
- NSCLC-Radiogenomics RNA sequencing data under GEO accession GSE103584;
- matched NSCLC-Radiogenomics imaging data from The Cancer Imaging Archive;
- NSCLC-Radiomics, also referred to as Lung1, imaging and clinical data from The Cancer Imaging Archive;
- Lung3 transcriptomic data under GEO accession GSE58661;
- HGNC gene annotation;
- MSigDB Hallmark gene sets.

Retain the original identifiers and source metadata when constructing the analysis workspace. The expected local directory structure is described in `docs/workspace_layout.md`.

Use of clinical and imaging data remains subject to the source repositories' access conditions, citation requirements, and applicable institutional policies.
